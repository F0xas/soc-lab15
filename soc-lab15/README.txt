Тема сайту: SOC (Security Operations Center)

ВАЖЛИВО: спочатку РОЗПАКУЙТЕ архів, не відкривайте файли всередині нього.

Структура:
  index.html      - головна сторінка (головний файл сайту, назва саме index.html!)
  css/style.css   - стилі
  js/script.js    - таби та модальне вікно
  Звіт_ЛР15.docx  - звіт

Локальний перегляд: двічі клацніть index.html (інтернет не потрібен).

Публікація на GitHub Pages (див. також звіт):
 1. github.com -> New repository -> назва, напр. soc-lab15 -> Public -> Create repository.
 2. "uploading an existing file" -> перетягніть index.html, папки css і js
    (вміст папки soc-lab15, а НЕ саму папку) -> Commit changes.
 3. Settings -> Pages -> Branch: main, папка /(root) -> Save.
 4. Через 1-2 хв сайт: https://ВАШ-ЛОГІН.github.io/soc-lab15/
